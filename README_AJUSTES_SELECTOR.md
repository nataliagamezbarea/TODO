# Selector de ramas

- `SELECCIONAR` es la opción predeterminada.
- `SELECCIONAR` no representa una rama: para Descargar y Visor Admin significa todas las ramas.
- El selector de index.html solo obtiene nombres de ramas. No carga `informacion.json`.
- Se eliminó la precarga de `informacion.json` que generaba 404 en ramas que no contienen ese archivo.
